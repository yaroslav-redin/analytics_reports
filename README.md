# Система аналитики опросов — МГУ им. Огарёва

Веб-приложение для автоматизированной обработки результатов студенческих опросов: загрузка Excel/CSV, очистка данных, ИИ-группировка свободных ответов, построение диаграмм и экспорт отчёта в Word.

## Стек технологий

- **Бэкенд:** Python 3.10+, FastAPI, Pandas, python-docx
- **Фронтенд:** Bootstrap 5, Chart.js, SortableJS (без шага сборки)
- **Авторизация:** OAuth 2.0 через ЭИОС МГУ им. Огарёва (`p.mrsu.ru`)
- **ИИ:** OpenRouter API (совместим с OpenAI SDK)

## Требования

- Python 3.10+
- Доступ к ЭИОС МГУ им. Огарёва

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone <url>
cd survey_analytics_app

# 2. Создать виртуальное окружение
python -m venv venv
venv\Scripts\activate.bat        # Windows
# source venv/bin/activate       # Linux / macOS

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Настроить переменные окружения
cp .env.example .env
# Отредактировать .env — указать EIOS_CLIENT_ID, EIOS_CLIENT_SECRET, OPENROUTER_API_KEY

# 5. Запустить сервер (порт 64548 зарегистрирован в ЭИОС OAuth)
uvicorn app.main:app --reload --port 64548
```

Открыть в браузере: [http://localhost:64548](http://localhost:64548)

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните значения:

| Переменная | Описание |
|---|---|
| `EIOS_CLIENT_ID` | ID приложения в OAuth ЭИОС |
| `EIOS_CLIENT_SECRET` | Секрет приложения в OAuth ЭИОС |
| `EIOS_REDIRECT_URI` | URI обратного вызова |
| `SESSION_SECRET_KEY` | Произвольная строка для подписи сессионных cookies |
| `OPENROUTER_API_KEY` | Ключ OpenRouter для ИИ-группировки ответов |

## Рабочий процесс (6 шагов)

1. **Загрузка** — загрузить один или несколько файлов `.xlsx` / `.csv`
2. **Листы** — выбрать нужные листы, настроить подписи файлов
3. **Вопросы** — выбрать вопросы для анализа, сопоставить их между файлами, при необходимости сгруппировать свободные ответы через ИИ
4. **Разделы** — распределить вопросы по разделам отчёта, задать порядок
5. **Анализ** — построить таблицы и диаграммы (столбчатые, круговые, накопленные)
6. **Экспорт** — скачать отчёт в формате `.docx`

## Поддерживаемые форматы файлов

- `.xlsx` — Excel (все листы)
- `.csv` — CSV с автоопределением разделителя и кодировки

## Авторизация

Вход выполняется через OAuth 2.0 ЭИОС МГУ им. Огарёва. Для работы приложения необходимо зарегистрировать `redirect_uri` (`/signin-eios`) в личном кабинете разработчика ЭИОС. Сессия действует 6 часов; загруженные файлы автоматически удаляются по истечении сессии.
