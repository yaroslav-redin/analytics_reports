Титульный лист
Вставляется в самое начало аналитического отчёта на отдельной странице. Гриф «УТВЕРЖДАЮ» — отдельной плашкой в правом верхнем углу (1×1 таблица без границ). Тело — заголовок, вводный текст и реквизиты исследования. Если оба поля очистить — титульный лист не создаётся.
Каждая строка — отдельный абзац внутри плашки, центрирован. Первая строка («УТВЕРЖДАЮ») идёт жирным.
Синтаксис разметки: # Заголовок — центрированный жирный заголовок; **текст** внутри строки — жирный фрагмент (например, ключи «**Цель исследования** – …»); пустые строки разделяют абзацы. Поля документа уже выставлены по ГОСТ: 2/2/3/1,5 см.

Промпт — выводы по разделам
Формируется один абзац-вывод на каждый раздел отчёта. Для вопросов без раздела выводы не генерируются. В качестве входных данных модель получает все вопросы раздела со статистикой ответов целиком.

Промпт — итоговые выводы по опросу
Формируется одним вызовом LLM в конце отчёта на отдельной последней странице. Модель получает ВСЕ вопросы опроса со статистикой ответов, сгруппированные по разделам. В выводах должно быть отражено, что респонденты предлагают ввести и от чего отказаться в работе университета — материал берётся и из свободных, и из оценочных вопросов.
Кем выступает модель при формулировании итоговых выводов
Объём, структура, обязательные акценты (по умолчанию: 4–5 выводов × 5–6 предложений)
Эталонный абзац — модель ориентируется по нему на стиль и плотность мысли
Достаточно для 4–5 абзацев по 5–6 предложений (рекомендовано 1500–2500)
